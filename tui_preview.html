🚀 Архитектура и запуск TUI

Как будет включаться и настраиваться новый режим:

  • Запуск через аргумент: Команда mycal -tui или mycal --tui мгновенно запускает графический полноэкранный интерфейс вместо классического меню.
  • Пункт в настройках: В меню настроек программы добавляется опция TUI по умолчанию: [Вкл / Выкл]. Если включено — обычный запуск mycal открывает TUI сразу, а классический CLI доступен через mycal --no-tui или прямые подкоманды (view, add, export).
  • Совместимость с CLI: Все существующие строчные команды скриптов продолжают работать без изменений.

⌨️ Управление клавиатурой

Интуитивная эргономика без необходимости учить сложные комбинации:

  • Стрелки ↑ / ↓: плавное перемещение курсора по списку записей с мгновенным обновлением правой карточки.
  • Клавиша Tab / 1, 2, 3: быстрое переключение активного фокуса между колонками (Календарь → Список → Детали).
  • Клавиша Enter: открыть полную карточку / перейти внутрь.
  • Быстрые буквы: a — добавить запись, e или \ — редактировать текущую, d — удалить с подтверждением, t — настроить фильтр типов, / — живой поиск, s — экран настроек.
  • Esc / q: закрыть всплывающее окно, очистить строку поиска или выйти.

🎨 Визуальное оформление и технологии

Надёжность, красота и скорость без тормозов:

  • Библиотека реализации в Go: Использование экосистемы Bubble Tea + Lip Gloss (от Charm.sh) — признанный стандарт современных красивых TUI для Go, обеспечивающий чистую компоновку, цветовую палитру ANSI/256/TrueColor и поддержку Windows Terminal, macOS и Linux.
  • Автоадаптация к размеру окна: При изменении размера терминала сетка динамически подстраивается; на небольших экранах правая панель деталей автоматически прячется или переключается по Enter в полноэкранный диалог.
  • Псевдографика Unicode: Аккуратные тонкие рамки (│, ─, ╭, ╮), иконки статусов и аккуратные бейджи длительности.
