# MyCalendar CLI

Удобная и быстрая консольная утилита для учета времени и ведения расписания прямо из терминала. Позволяет добавлять, редактировать, просматривать и удалять записи, а также экспортировать данные в CSV.

## Особенности
- **Кроссплатформенность:** Доступны сборки для Windows, macOS и Linux.
- **Работа без интернета:** Все данные хранятся локально в формате JSON.
- **Интерактивный UI:** Полноценное консольное меню с поддержкой цветного вывода и горячих клавиш (ввод букв для быстрой навигации по всем меню).
- **Умный парсер дат:** Поддержка ввода частичных дат (например, только года `2026` или месяца-года `12.2025`), а также умное распознавание времени (ввод `15` означает `15:00`).
- **Атомарные операции:** Безопасное сохранение данных и автоматические бэкапы.
- **Повторяющиеся записи:** Умный алгоритм создания дублей для повторяющихся каждый день/неделю/месяц записей без перегрузки базы данных (через DRY ссылки по ID `_r`).
- **Data Doctor (Проверка целостности):** Автоматическое сканирование `mycal.json` при старте на предмет битых ссылок и предложений по их авто-очистке.
- **Умные частые имена:** Автоматический трекинг часто используемых названий записей и их автодополнение (вызов по `/` во время ввода имени), с возможностью ручного управления в Настройках.
- **Многообразие отображения:** Возможность просмотреть сразу все подробности списка через команду `all` или детально фильтровать записи по тексту через `/`.
- **Быстрое редактирование:** Возможность быстро редактировать запись напрямую из меню просмотра, добавив слэш перед номером или ID (например, `\3`).
- **Индивидуальные повторы:** Возможность гибко переопределять отдельные повторения повторяющейся записи, сохраняя при этом связь с оригиналом (вы можете установить уникальный статус, время или комментарий конкретному дню из серии повторов).
- **Экспорт и массовые операции:** Экспорт в CSV, каскадное удаление повторов, просмотр записей за выбранный период.

## Запуск
Скачайте актуальную версию для вашей ОС из раздела [Releases](https://github.com/khameleonium/MyCal/releases) и запустите в терминале:

```bash
# Пример для Linux / macOS
chmod +x mycalendar-linux-amd64
./mycalendar-linux-amd64

# Пример для Windows
mycalendar-windows-amd64.exe
```

Или соберите из исходников:
```bash
go build -o mycalendar .
./mycalendar
```

## Разработка
```bash
go test ./...      # модульные тесты (parser, storage, calendar, config, app)
go vet ./...
gofmt -l .         # должно быть пусто
```
Проверки `gofmt` / `go vet` / `staticcheck` / `go test -race` и кросс-сборка
запускаются в CI (`.github/workflows/ci.yml`).

### Структура пакетов
| Пакет | Ответственность |
|-------|-----------------|
| `models`   | Типы данных, разбор конфига, единый источник значений по умолчанию |
| `parser`   | Разбор и форматирование дат, времени и периодов |
| `storage`  | Атомарная загрузка/запись JSON, режимы разбиения файлов, миграция |
| `calendar` | Доменный сервис: CRUD, индексация, повторяющиеся записи |
| `config`   | Чтение/запись файла настроек |
| `color`    | ANSI-раскраска с детектом TTY и `NO_COLOR` |
| `app`      | Интерактивный UI и CLI-подкоманды (разбит по экранам) |

## Быстрые команды
Утилиту можно запустить с флагами для быстрого выполнения действий без входа в главное меню:
- `mycalendar add` (или `a`) — быстрое добавление записей
- `mycalendar today` (или `t`) — показать записи на сегодня
- `mycalendar week` (или `w`) — показать записи за текущую неделю
- `mycalendar month` (или `m`) — показать записи за текущий месяц
