# MyCalendar CLI

Удобная и быстрая консольная утилита для учета времени и ведения расписания прямо из терминала. Позволяет добавлять, редактировать, просматривать и удалять записи, а также экспортировать данные в CSV.

## Особенности
- **Кроссплатформенность:** сборки для Windows, macOS и Linux, без зависимостей и без интернета.
- **Локальное хранение:** данные в обычном JSON рядом с программой. Режимы: один файл, по годам или по месяцам — при смене режима файлы перегруппируются автоматически.
- **Интерактивное меню + быстрые CLI-команды:** цветной вывод, горячие клавиши буквами в обеих раскладках.
- **Умный ввод:** неполные даты (`2026`, `12.2025`, `10-15`) и время в любом виде (`14:30`, `1430`, `14.30`, `9`, `24`). Некорректные даты (`32.01.2026`) переносятся по календарю; реакция настраивается (выкл / спросить / исправлять / переспрашивать).
- **Повторяющиеся записи:** каждый день / неделю / месяц до указанной даты. Каждое повторение — самостоятельная запись, связанная с остальными в серию; правка и удаление — по одной записи или всей серией.
- **Надёжное сохранение:** запись атомарная (temp → fsync → rename) с резервной копией `.bak`. Понятные сообщения об ошибках («нет прав доступа», «недостаточно места на диске»). Повреждённый файл не затирается — он откладывается как `*.corrupt-<дата>`, работа продолжается из `.bak`.
- **Data Doctor:** при старте — проверка целостности (пустые/битые ID, дубли, отрицательная длительность, нераспознанное время) с предложением автоматической починки.
- **Частые имена:** автотрекинг часто используемых названий и автодополнение по `/`, ручное управление в Настройках.
- **Просмотр:** список за период/неделю/месяц/всё; `all` — все подробности сразу; `/текст` — фильтр текущего списка; `\N` / `\ID` — быстрое редактирование.
- **Экспорт в CSV** (UTF-8 с BOM, открывается в Excel) за любой период.

## Запуск
Скачайте актуальную версию для вашей ОС из раздела [Releases](https://github.com/khameleonium/MyCal/releases) и запустите в терминале:

```bash
# Пример для Linux / macOS
chmod +x mycalendar-linux-amd64
./mycalendar-linux-amd64

# Пример для Windows
mycalendar-windows-amd64.exe
```

Или соберите из исходников:
```bash
go build -o mycalendar .
./mycalendar
```

## Разработка
```bash
go test ./...      # модульные тесты (parser, storage, calendar, config, app)
go vet ./...
gofmt -l .         # должно быть пусто
```
Проверки `gofmt` / `go vet` / `staticcheck` / `go test -race` и кросс-сборка
запускаются в CI (`.github/workflows/ci.yml`).

### Структура пакетов
| Пакет | Ответственность |
|-------|-----------------|
| `models`   | Типы данных (`Session`, `Calendar`, `Config`), единый источник значений по умолчанию |
| `parser`   | Разбор и форматирование дат, времени и периодов |
| `storage`  | Атомарная загрузка/запись JSON, режимы разбиения файлов, миграция, восстановление из `.bak` |
| `calendar` | Доменный сервис: запросы, изменения, серии повторов, проверка/починка целостности |
| `config`   | Чтение/запись файла настроек, обработка повреждённого файла |
| `color`    | ANSI-раскраска с детектом TTY и `NO_COLOR` |
| `app`      | Интерактивный UI и CLI-подкоманды (по одному файлу на экран) |

### Формат данных
Плоский список самодостаточных записей — без вложенной группировки по датам:

```json
{
  "sessions": [
    {
      "id": "20260615143000",
      "time": "14:30",
      "name": "Совещание",
      "type": "Планёрка",
      "duration": 45,
      "notes": "",
      "status": "Активно",
      "series_id": ""
    }
  ]
}
```

`id` = `ГГГГММДДЧЧММnn` (дата и время + двузначный счётчик в пределах минуты).
Записи одной серии повторов имеют общий непустой `series_id`.

## Быстрые команды
Утилиту можно запустить с флагами для быстрого выполнения действий без входа в главное меню:
- `mycalendar add` (или `a`) — быстрое добавление записей
- `mycalendar today` (или `t`) — показать записи на сегодня
- `mycalendar week` (или `w`) — показать записи за текущую неделю
- `mycalendar month` (или `m`) — показать записи за текущий месяц
